Tiếng Việt
Azure Community / Launcher Support 🛠 là cộng đồng chuyên sâu dành cho người dùng muốn chạy và tối ưu Minecraft Java Edition trên iPhone/iPad. Tại đây bạn có thể trao đổi cấu hình theo từng đời máy, xử lý lỗi khởi chạy, chọn renderer/mod phù hợp và tham khảo video hướng dẫn trên TikTok @nexusamethyst.
Launcher iOS là gì? Là trình khởi chạy chuyên biệt giúp đưa Minecraft Java Edition lên iOS/iPadOS vốn không chạy trực tiếp file .jar và máy ảo Java của desktop. Launcher tự động chuẩn bị tài nguyên game, runtime Java (JVM), modloader (như Fabric) và lớp dịch đồ họa để game hoạt động trên phần cứng di động.
Witch Launcher là gì? Là launcher Minecraft Java trên iOS hướng đến sự gọn gàng, trực quan và thao tác nhanh, phù hợp để quản lý phiên bản, bật/tắt mod tối ưu và tinh chỉnh thiết lập cơ bản.
Amethyst Launcher là gì? Là launcher mã nguồn mở cho iOS tập trung vào hiệu năng và khả năng tùy biến chi tiết, hỗ trợ quản lý nhiều phiên bản Java runtime, đổi renderer đồ họa, tùy chỉnh tham số JVM và cấu hình theo thiết bị.
Cơ chế hoạt động & thành phần cốt lõi Khi khởi chạy, launcher chuẩn bị file game cùng runtime Java tương ứng (Java 17, Java 21 hoặc Java 25 tùy phiên bản Minecraft) và tải modloader như Fabric kết hợp các mod tối ưu (Sodium, Lithium, FerriteCore, ModernFix). Các lệnh đồ họa OpenGL hoặc Vulkan được dịch sang Metal của iOS qua các renderer như MobileGlues, Zink, LTW, gl4es hoặc MoltenVK. Bắt buộc bật JIT thì mới chơi được game.
Chọn Renderer & cân đối tài nguyên Mỗi renderer phù hợp với từng phiên bản Minecraft, GPU và thiết lập shader khác nhau. Nên test từng thay đổi một, cấp phát RAM hợp lý và giảm render distance nếu máy nóng hoặc giật lag.

English
Azure Community / Launcher Support 🛠 is a dedicated hub for players running and tuning Minecraft Java Edition on iPhone and iPad. Join the community to share device-specific setups, troubleshoot launch issues, pick the right renderer and mods, and follow TikTok @nexusamethyst for tutorial videos.
What is an iOS Launcher? A specialized launcher app that brings Minecraft Java Edition to iPhone/iPad, which do not natively run desktop .jar packages or standard desktop JVM setups. It manages game versions, Java virtual machine (JVM) runtimes, modloaders (such as Fabric), and graphics translation layers on iOS.
Witch Launcher An iOS Minecraft Java launcher designed for a clean, approachable workflow with straightforward version and mod management plus practical setup options on mobile.
Amethyst Launcher An open-source iOS launcher focused on smooth Minecraft Java performance and granular control, supporting multiple Java runtimes, graphics renderers, JVM flags, and device-level tuning.
How It Works & Core Components The launcher prepares game files with a matching Java runtime (Java 17, Java 21, or Java 25 depending on the Minecraft version) and loads modloaders such as Fabric with optimization mods (Sodium, Lithium, FerriteCore, ModernFix). OpenGL or Vulkan rendering calls are translated into iOS Metal via renderers such as MobileGlues, Zink, LTW, gl4es, or MoltenVK. JIT is strictly required to play the game.
Choosing Renderers & Tuning Stability Different renderers suit different game versions, GPUs, and shader setups. Test one change at a time, balance RAM allocation, and lower render distance if the device heats up or stutters.
Installing via SideStore on iOS Install SideStore via a signing tool and sign in with your Apple ID → enable VPN / LocalDevVPN and a JIT helper such as StikDebug (JIT is required to play) → open SideStore and install the Launcher .ipa → go to Settings > VPN & Device Management to trust your Apple ID certificate → refresh inside SideStore before the 7-day limit on free Apple IDs.
