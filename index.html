Overview guide, core mechanics, performance tuning & community support links

Tiếng Việt
Azure Community / Launcher Support 🛠 là cộng đồng chuyên sâu dành cho người dùng muốn chạy và tối ưu Minecraft Java Edition trên iPhone/iPad. Tại đây bạn có thể trao đổi cấu hình theo từng đời máy, xử lý lỗi khởi chạy, chọn renderer/mod phù hợp và tham khảo video hướng dẫn trên TikTok @nexusamethyst.
Launcher iOS là gì? Là trình khởi chạy chuyên biệt giúp đưa Minecraft Java Edition lên iOS/iPadOS vốn không chạy trực tiếp file .jar và máy ảo Java của desktop. Launcher tự động chuẩn bị tài nguyên game, runtime Java (JVM), modloader (như Fabric) và lớp dịch đồ họa để game hoạt động trên phần cứng di động.
Witch Launcher là gì? Là launcher Minecraft Java trên iOS hướng đến sự gọn gàng, trực quan và thao tác nhanh—phù hợp để quản lý phiên bản, bật/tắt mod tối ưu và tinh chỉnh thiết lập cơ bản mà không mất nhiều thời gian làm quen.
Amethyst Launcher là gì? Là launcher mã nguồn mở cho iOS tập trung vào hiệu năng cao và khả năng tùy biến chi tiết, hỗ trợ quản lý nhiều phiên bản Java runtime, chuyển đổi linh hoạt giữa các renderer đồ họa, tùy chỉnh tham số JVM và cấu hình chuyên sâu theo từng thiết bị.
Cơ chế hoạt động & thành phần cốt lõi Khi khởi chạy, launcher chuẩn bị file game cùng runtime Java tương ứng (Java 17, Java 21 hoặc Java 25 tùy phiên bản Minecraft) và tải modloader như Fabric kết hợp các mod tối ưu phổ biến (Sodium, Lithium, FerriteCore, ModernFix...). Sau đó, các lệnh đồ họa OpenGL hoặc Vulkan của game được dịch sang API đồ họa Metal của iOS thông qua các renderer như MobileGlues, Zink, LTW, gl4es hoặc MoltenVK. Bắt buộc phải kích hoạt JIT thì mới có thể chạy và chơi được game.
Chọn Renderer & cân đối tài nguyên Mỗi renderer có ưu thế riêng tùy phiên bản Minecraft, GPU và việc dùng shader hay không. Khi đổi renderer, thêm mod hoặc bật shader, nên test từng thay đổi một, cấp phát dung lượng RAM hợp lý và giảm bớt render distance nếu máy nóng hoặc giật lag.
Cách cài bằng SideStore trên iOS (chi tiết) Cài SideStore qua công cụ ký ứng dụng và đăng nhập tài khoản Apple ID → bật VPN / LocalDevVPN và công cụ kích hoạt JIT như StikDebug (bắt buộc bật JIT mới chơi được) → mở SideStore, chọn file .ipa của Launcher để cài đặt → vào Cài đặt → Quản lý VPN & Thiết bị để tin cậy chứng chỉ Apple ID → mở SideStore làm mới (Refresh) định kỳ trước mốc 7 ngày nếu dùng Apple ID miễn phí.

Azure Community / Launcher Support 🛠 is a dedicated hub for players running and tuning Minecraft Java Edition on iPhone and iPad. Join the community to share device-specific setups, troubleshoot launch issues, pick the right renderer and mods, and follow TikTok @nexusamethyst for tutorial videos.
What is an iOS Launcher? A specialized launcher app that brings Minecraft Java Edition to iPhone/iPad, which do not natively run desktop .jar packages or standard desktop JVM setups. It manages game versions, Java virtual machine (JVM) runtimes, modloaders (such as Fabric), and graphics translation layers on iOS.
Witch Launcher An iOS Minecraft Java launcher designed for a clean, approachable workflow with straightforward version/mod management and practical configuration options for fast setup on mobile.
Amethyst Launcher An open-source iOS launcher focused on smooth Minecraft Java performance and granular control, allowing deeper management of Java runtimes, graphics renderers, JVM flags, and device-level tuning.
